# Smart White Cane for the Visually Impaired (Virtual Prototype v1)

Built with passion and technical independence by **TALIA KAMAL**.

## 📌 Project Overview
This project is the first milestone in a 4-year innovation roadmap dedicated to developing assistive high-tech devices. This is a functional, high-fidelity virtual prototype of an intelligent white cane designed to restore autonomy and privacy for visually impaired individuals. By shifting logic from complex smartphone dependencies directly to an embedded micro-system, this device enables smart distance estimation safely and efficiently.

## 🚀 Key Features
* **Embedded Distance Detection:** Utilizes ultrasonic wave sensing to compute distance calculations in real-time.
* **MicroPython Framework:** Built completely using Python logic tailored for microcontrollers.
* **Optimized Indentation & Architecture:** Developed entirely by hand to maintain maximum efficiency and clean code standards.
* **MIT Licensed:** Secured and fully protected code infrastructure.

## 🔌 Hardware Architecture (Virtual Setup)
* **Microcontroller:** Raspberry Pi Pico (Driven by MicroPython v1.28.0)
* **Sensor Module:** HC-SR04 Ultrasonic Distance Sensor
* **Power Grid:** Configured via VBUS power distribution and solid GND infrastructure

## 📂 File Structure
* `main.py`: The core firmware script processing physical distances y the second.
* `diagram.json`: The complete virtual wiring map and component layouts.
